# Saved drafts

`mcffl-2026.json` records the completed MCFFL 2026 draft: 10 teams, 15 rounds,
and 150 picks in their original order, drafted September 6–7, 2026.

To replay it, open **Board settings → Replay MCFFL 2026 Draft** in the tracker.
The app bundles this JSON at build time, so replay remains available after resetting
the live draft. The tracker uses the current
published board and current recommendation code while keeping live draft state
unchanged. The archive contains teams, player identities, pick order, and pick
timestamps; it contains no credentials or frozen projections.
